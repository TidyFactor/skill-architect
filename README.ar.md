# مهندس مهارات تايدي فاكتور (TidyFactor Skill Architect v1.0.0)

> **طبقة الحوكمة ومحرك منهجية المهارات لوكلاء البرمجة بالذكاء الاصطناعي**  
> يطبق القواعد الهيكلية الثمانية لمهارات تايدي فاكتور عبر بيئات Antigravity وClaude Code وCursor وCodex وWindsurf.

---

## 🏛️ نظرة عامة

يُعد `tidyfactor-skill-architect` طبقة الحوكمة المركزية التي تحكم كيفية بناء وتدقيق وتطوير المهارات داخل منظومة TidyFactor. يضمن بقاء المهارات خفيفة ومقتصدة في استهلاك التوكينات.

---

## ⚡ الأوامر السريعة

| الأمر | الهدف | الوصف |
|---|---|---|
| `init` | "انشئ مهارة لـ X" | إنشاء مهارة جديدة وفق موجه `SKILL.md` (حوالي 350 توكين) مع هيكل ملفات أدنى. |
| `audit` | "افحص هذه المهارة" | تقييم المهارة الحالية وتحديد الإصلاحات المطلوبة بدقة. |
| `grow` | "هل أضيف ملف جديد؟" | تقييم التوسع المطلوب وفق محفزات النمو الحجمية والفرعية. |

---

## 📐 القواعد الهيكلية الثمانية

1. **انضباط الموجه (Dispatcher Discipline)**: ملف `SKILL.md` هو موجه للأوامر ولا ينفذ المهام بنفسه.
2. **سير عمل واحد = مخرج واحد**: كل سير عمل ينتهي بقائمة تحقق واضحة.
3. **الذاكرة التشغيلية**: حقائق وقواعد تقنية فقط بدون كلام إنشائي.
4. **منع المجلدات الفارغة**: عدم إنشاء مجلد لملف واحد.
5. **عزل الفلسفة والتوجه**: عزل الفلسفة في `memory/philosophy.md`.
6. **النمو المشروط بالمحفزات**: إضافة الملفات فقط عند تحقق محفزات حجمية أو فرعية.
7. **الجودة والأدوات المحلية**: استخدام سكربتات في `tools/` تعتمد على الأدوات الرسمية (`node` و`python`).
8. **التطابق عبر البيئات والإصدارات**: سلوك متطابق وإدارة إصدارات صارمة عبر `CHANGELOG.md`.

```bash
npm run validate

npm run build
```
