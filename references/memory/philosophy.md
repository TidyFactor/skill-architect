# Philosophy (human-facing only — never load this into an operational file)

This file exists for a person reading the repo, not for an agent executing a skill. No command, workflow, or skill.md in this system references it. If you find a reference to it from an operational file, that's a spec violation — see spec.md rule 7.

Source language (Wael Salaheldin Omar, TidyFactor-Skills):

> The Prompt Engineering Next step — Capability Engineered Skills. AI Native, Token Friendly, Simple by Default, Expandable by Need, Convention over Configuration, Capability First, Composable, No Empty Structures. A Skill is not executed — a Skill is assembled.

Reduce files whenever possible. Reduce instructions whenever possible. Reduce duplicated knowledge. Reduce token usage. Reduce cognitive load. Increase clarity, reuse, consistency, predictability.

When generating a Skill, ask: what capability is being added, what complexity can be removed, what repetitive work can be automated, what knowledge should become reusable. Never ask how to make a Skill more sophisticated — ask how to make it simpler.
