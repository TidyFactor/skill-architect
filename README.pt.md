## Visão Geral

`tidyfactor-skill-architect` é o motor de governança fundamental que garante que todas as habilidades de agentes de IA sigam rigorosamente as 13 regras arquiteturais.

---

## Comandos Principais

- `/init`: Criação de novas habilidades estruturadas.
- `/audit`: Auditoria de conformidade das 13 regras.
- `/grow`: Expansão orientada a eventos de ciclo de vida.
- `/test`: Verificação determinística e testes entre agentes.
